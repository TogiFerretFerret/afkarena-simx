Four independent pure Rust processes completed **80 measured fixed-fixture battles in 62.1349 seconds: 1.28752 battles/second aggregate**. Each also ran the original three warmups. Their measured windows shared 61.3191 seconds of overlap. The aggregate uses 80 divided by the interval from the earliest measured start to the latest measured end; it does not sum individual rates.

This is 3.35× the matching single-process baseline's 0.38436 battles/second. Each worker retained its original 20/3 workload and matched the same pinned Node reference for every non-timing report field, including callbacks, RNG bits, final serialized/state capture, host events, class counters and complete host-tape consumption. Every worker executed 309,060 measured callbacks, checksum 278296133, and all 23 GC backedges. There were no source, library or binary changes during the run.

Peak simultaneous RSS for all workers plus the Node monitor was **13.185 GiB**, below the 14 GiB cap. Individual process high-water marks were about 3.22 GiB. Startup, table loading and warmups are outside the measured battle windows but remain under the memory cap. The only instrumentation wrapped the host wall-clock argument to record two common UNIX-epoch timestamps and delegate the original Date.now call unchanged.
