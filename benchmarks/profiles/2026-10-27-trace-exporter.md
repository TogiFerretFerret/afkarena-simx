# Complete-state exporter attribution and reuse

The live copied-source `--jitless` diagnostic was profiled after Node's native SHA-256 digest was installed. This measures diagnostic overhead, not simulation throughput. The 10-second sample (`2026-10-27T18-05-30.378Z-process-32257`) attributes 33.05% self time to recorder serialization, 24.85% to snapshot construction, 10.29% to value encoding, 11.34% to garbage collection and 4.75% to numeric bit formatting. Native crypto `update` accounts for only 0.35%. An earlier sample caught cold Babel work and is retained separately to distinguish startup from graph capture.

The exporter now caches numeric encodings by exact Number identity, handling positive/negative zero separately and bypassing all NaNs. Its bounded cache preserves NaN payload/sign through the original DataView path. A typed-array brand regular expression is allocated once rather than once per object.

Every source own key and descriptor is still read on each snapshot. A property representation is reused only if its descriptor flags and value are unchanged; NaNs require raw-bit equality. Object/function/symbol children and accessor function identities are still encoded and traversed, even if their parent edge is unchanged. Ordinary node representations are reused only when all property records, prototype encoding, kind, extensibility and function code match. Native internal-state records retain their original fresh capture path. A reused immutable representation can reuse its serialized digest without serializing the same node again. Traversal order and complete Merkle protocol are unchanged.

The source graph and exporter output remain separate: returned graph records are exporter-owned immutable representations. Diagnostic consumers must not modify captured records.

Validation includes all portable exporter tests, 20,008 adversarial numeric inputs across three complete snapshots (cache eviction, negative zero, infinities, signed/payload NaNs), and complete graph-byte plus compact-hash comparisons through 18 descriptor/native-state mutations. Mutations include nested children, aliases, deletion/reinsertion, holes, symbols, property flags, throwing accessors, function prototypes, prototype replacement, extensibility, maps/sets, dates, typed buffers and changing NaN payloads. Accessors are never invoked.

`node tools/benchmark-trace-export.mjs 20` samples a real seed-2026 engine after each source callback frame. Its cached and uncached complete graph hashes match at every sampled state. Interleaved Node JIT measurements were 1,138ms cached versus 1,405ms uncached (1.23x diagnostic speed). Concurrent compiler work and the different JIT setting limit this comparison; it is neither a completed battle trace nor a battle throughput result. The timing and all sampled state hashes are committed in `benchmarks/results/2026-10-27T18-09-36.778Z-trace-export-cache.json`.
