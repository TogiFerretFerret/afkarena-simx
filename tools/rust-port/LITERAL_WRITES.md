The isolated `literalPropertyWrites` experiment reuses guarded read-site tickets for writes to ordinary own writable data properties. Compound reads and writes share the same ticket. The actual write revalidates the receiver, current physical slot key and current writable Data descriptor after evaluating the RHS. It stores the new Value without changing descriptor flags or retaining a receiver/value in the cache. No shape version, bloom filter or public mutation invariant is required.

Arrays, function aliases, mapped arguments, accessors, missing/readonly properties and all exotic receivers use the unchanged generic setter, preserving strict errors, prototype setters, receiver identity, coercion and deletion behavior. Cached slot positions tolerate callbacks and GC ID reuse because every hit checks the current object and descriptor. Computed members keep their original implementation. The compiler option defaults to false.

Correctness evidence: 33 source cases with caching OFF/ON, five compiler checks and six native runtime tests pass. Directed cases cover RHS descriptor replacement, strict/sloppy readonly writes, delete/reinsert, variable reassignment after capturing a receiver, valueOf-driven descriptor mutation, inherited setters, arrays, legacy function properties, nonextensible objects and descriptor flags. Native tests preserve raw signaling NaN, signed zero and payload bits, and span 23 actual collections with recycled object/function IDs.

There is **no repeatable Unit.update speed gain yet**. Two same-binary comparisons each ran 30,000 original updates per variant with all 150,220 ordered fixture events and selected state bits matched against pinned jitless Node. The first measured 1.0257x (11,921 versus 12,228 updates/sec); the repeat measured 0.9864x (12,523 versus 12,353). This difference is within observed variation, so integration is not recommended on this evidence alone. These are controller updates/sec with explicit fixture observers and callbacks, not battles/sec or full mechanics qualification.

No main runtime or compiler source was changed. Both timing reports and generated/source/oracle archives are committed on the isolated branch for review.
