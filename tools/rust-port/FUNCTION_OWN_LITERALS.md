Function own-data literal read candidate

The existing ordinary-object cache-hit path is unchanged. After its miss, a function value resolves its current function record to an object on each access. Only an ordinary function object with no mapped bindings may supply a fresh keyed physical data slot. `arguments` and `caller` always use the original lookup. Prototype caching remains unchanged. A slow getter's return value is preserved; the next access learns only the descriptor present after the callback.

The cache stores locations and keys, never a function identity or value. Existing weak string-key invalidation applies. Four new native tests cover raw negative-zero/NaN payloads, current function/object ID reuse through 23 collections, legacy exclusions and invalid identities, descriptor mutation, and diagnostic receiver/key/bit recording. All 115 library tests passed. The independent Node source gate passed 31 cases (62 OFF/ON observations), including recursive active arguments, mapped arguments, strict legacy throws and function mutations.

`function_own_literal_slots_enabled` controls this candidate independently. Unit and original callback-drain tools prepare separate binaries and bind their input/binary hashes for later paired timing. Full-battle throughput remains unmeasured; this candidate awaits combined qualification. These are component gates, not full-battle qualification.

The first paired source-controller experiment is positive: three alternating trials measured Unit updates at 13,266/s OFF versus 14,532/s ON (1.095×), and original callback drain at 99,473/s versus 106,995/s (1.076×). All 150,220 Unit events and 38,400 drain events per trial, ordered outputs and selected state bits match independent Node. These are component rates, not battles per second. Compilers were stopped for timing; an approved 0.3-second debug-cache deletion may overlap the beginning. The first Unit pair measured 1.006×, later pairs 1.115× and 1.171×. The small sample has no confidence interval; full-battle admission and speed remain unqualified. The candidate was excluded from the already frozen combined wave.
