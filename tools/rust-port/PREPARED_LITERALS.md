This isolated experiment moves preparation of literal read sites inside loops to generated function entry. A Copy handle stores the runtime cache index and canonical key, avoiding the atomic site ticket, cache resize and key-initialization checks on repeated reads. Every read still checks the current object kind, current physical slot key and data descriptor, reads the live value, and retains slow-path getters, inherited receivers and diagnostics. Handles do not borrow the runtime and must remain in their originating runtime, like object/environment IDs. Helper-split functions remain excluded, and the compiler option `preparedLoopLiterals` defaults to false.

The experiment is **not recommended for integration**. Preparing untaken loop body sites costs time: the original Unit.update has 37 eligible sites, including empty buff loops. A short same-binary trial suggested 1.032x, but the longer 30,000 updates per variant measured **0.923x** (8,618 versus 7,954 updates/sec). Shared host load limits precise timing interpretation; there is no demonstrated speed win. These are controller updates/sec, not battles/sec.

Both trials preserved all ordered fixture events and selected state bits against pinned jitless Node. The longer run compared 150,220 events per trial. Native locals, numeric operators and own-property caches were enabled in both variants; only loop-site preparation changed. Three additional eligible sites belong to fixture helpers, so the result covers the unchanged controller and its explicit observer/callback fixture, rather than isolating controller machine instructions.

`check-prepared-literals.mjs` passes 20 source cases with cache OFF/ON, covering mutation, getter/setter ordering, inherited receivers, exotic values and separate compiled modules. The runtime property-slot suite passes five tests, including an explicit prepared handle retained across 23 actual GC collections and recycled object/function IDs with raw NaN and signed-zero values. The compiler's five focused placement checks cover loop reads, nested-function exclusion, default-off behavior and split functions.

No main compiler/runtime files were changed for this experiment.
